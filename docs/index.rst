Contact Manager
===============

Welcome to the documentation for the Contact Manager application.

This application provides functionality for managing contacts using
an SQLite database.

Features
--------

* Create contacts
* View all contacts
* Search contacts by name
* Search contacts by email
* Search contacts by phone
* Update contacts
* Delete contacts
* Validate email addresses
* Validate phone numbers
